# clear_cut_ML - Detection and classification of clear-cutting using machine learning

The aim to this porject is to develop an algorithm that, using freely available satellite imagery, can detect clear-cuts and segment them.

## Data

| Data | Source | Usage |
|---|---|---|
| Sentinel-2 L2A | Sentinel-2 L2A (Copernicus), accessed via Microsoft Planetary Computer | ML classification |
| Reference dataset | Global Forest Change (Hansen/UMD, GFC-2024-v1.12) | ML labels|

## The pipeline in detail

1. `download_sentinel.py`

The first part of the pipeline is to download the sentinel2 data from copernicus. It is done using *microsoft planetary computer* that doesn't need login to access data. 

The following parameters can be configured in the script:  
* Dates : Specify the 2 dates you want to download (work as a pair of date) corresponding to the before and after images. You can specify a specific date or a period and the script finds the image with the less cloud cover around this period.

* Bounding box :  You will need to specify a bounding box for the study zone in this format : `# lon_min, lat_min, lon_max, lat_max (EPSG:4326)`

* Spectral bands : You can specify which spectral bands you want to download. (e.g. B02, B03, B04, B08...).

Sentinel-2 L2A stores reflectance as integers (DN), using the formula: `reflectance = DN / 10,000`
From January 2022 (processing baseline 04.00), the ESA changed the encoding. It shifted all values by +1,000. The formula becomes: `reflectance = (DN − 1,000) / 10,000`

2. `download_hansen.py` 

This scripts download the forest-loss reference data from the *Global Forest Change* dataset.

You will need to specify a reference image downloaded the step before that will give the grid (CRS, pixel size, extent) for computation. 

3. `create_dataset.py`

This scripts create the dataset based on the 2 previous steps. 

It prepares the input features from the two acquisition dates and generates the corresponding reference labels. The resulting dataset is saved as `.npz` file that is loaded by the `train_model.py` script. 

4. `train_model.py` 

This script loads the dataset generated by create_dataset.py and trains a random forest  model that will be the baseline.
